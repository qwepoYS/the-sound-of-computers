🧪 Test Your Code in an Online Sandbox

No files to set up. Open one of these, make a new project, and paste the two blocks into the HTML and JavaScript panels:

CodePen ↗ JSFiddle ↗ StackBlitz ↗
1. HTML panel (index.html in StackBlitz)
<button id="play">▶ Play 440 Hz</button>
2. JavaScript panel (index.js in StackBlitz)
document.getElementById('play').onclick = () => {
  const ctx = new AudioContext();
  const osc = ctx.createOscillator();
  const gain = ctx.createGain();
  osc.type = 'sine';
  osc.frequency.value = 440;
  gain.gain.value = 0.2;
  osc.connect(gain).connect(ctx.destination);
  osc.start();
  osc.stop(ctx.currentTime + 2);
};

Click the Play button in the preview pane. The click counts as the user gesture browsers need before they allow sound.

⬇️ Tweak Guide

Find these three values in the JavaScript block, change them, then run it again.

440➔Pitch

Change this number to alter the pitch. Try 261.63 for C4, or 880 for a higher A note.

0.2➔Volume

Change this number (between 0.0 and 1.0) to lower or raise the volume. Start around 0.1 to 0.3 and increase slowly, because 1.0 is full volume and can be very loud.

'sine'➔Wave shape (timbre)

Change this word to 'square' (8-bit game sound), 'sawtooth' (buzzy brass) or 'triangle' (soft and muffled) to completely change the sound.
